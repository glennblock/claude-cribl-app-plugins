# Claude Cribl App Plugins

A collection of Claude plugins designed to streamline Cribl app development and deployment workflows.

## Plugins

| Plugin | Description |
|--------|-------------|
| **[app-creation](./plugins/app-creation/README.md)** | Structured workflow for authoring Cribl Apps. Guides you from problem definition through app brief generation and implementation, with validation at each step to ensure your app is well-scoped and ready. |

## Getting Started

1. Navigate to the plugin directory of interest (e.g., `plugins/app-creation/`)
2. Review the plugin's README for setup and usage instructions
3. Follow the workflow outlined in each plugin's documentation
